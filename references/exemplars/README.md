# Exemplars

Annotated, verbatim excerpts from the group's papers, one file per section per category:
`<category>/<section>.md` (introduction-opening, introduction-aims, methods-training,
methods-statistics, results, discussion-opening, limitations, conclusion, captions).

Each excerpt has:
- **Why:** the moves it demonstrates.
- **Do differently now:** where it predates a group decision in `../open-questions.md` (e.g. `i)` → `(i)`).
- **Edited:** any typo fixed. The text is otherwise verbatim, apart from removed conversion artefacts.

Source: Phase 4 of `docs/style-guide-plan.md`, chosen from high-weight, non-held-out papers.
To add one, copy a paragraph verbatim from a group paper and give it the same three fields. Only use text
from published papers or preprints, or from unpublished drafts with the authors' agreement.
