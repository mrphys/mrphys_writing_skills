## 2605.26127v1: Rapid online deep artifact suppression for real-time spiral bSSFP CMR with blipped-CAIPI s

**Why:** The reference Statistics paragraph: software and version, significance threshold, how variables are summarised, then one sentence per comparison naming the test, ending with Bland-Altman for agreement.

> Statistical analyses were performed using SciPy (version 1.10.1) in Python, with a p-value <0.05 considered statistically significant. Continuous variables are reported as mean ± standard deviation. Comparisons of quantitative image scoring (edge sharpness, eSNR and bmCR) across all three groups were performed using one-way repeated measures analysis of variance (ANOVA) with post hoc testing using Holm correction for significant results. Qualitative image quality rankings between RT-SMS-DL and RT-SMS-CS were compared using paired preference testing, with a binomial test against a null hypothesis of equal preference (p=0.5). Likert-scale qualitative image quality scores for RT-SMS-DL and reference-standard BH images were compared using a Wilcoxon signed-rank test. Mean ventricular volumes, function and mass measured using RT-SMS-DL and reference-standard BH techniques were compared using a paired t-test, and agreement was assessed using Bland-Altman analysis.
